# ELMAJIKU Vault 🔐

An offline-first personal digital vault for mobile, described in the portfolio as combining hardware-backed biometrics with client-side AES-256 GCM encryption.

## Technology
- Flutter 3 and Dart
- AES-256 GCM
- Drift / SQLite
- Biometric authentication

## Security notes
Encryption keys and sensitive data should remain protected by the app's intended secure-storage design. Do not commit credentials, keys, local databases, or signing files.
